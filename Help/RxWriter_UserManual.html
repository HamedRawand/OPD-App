Getting Started — Login & First Setup

How to launch Rx Writer, sign in, and set up your account

Launching the App & Logging In

Double-click the Rx Writer shortcut on your desktop to open the application. The Login window appears immediately — no network connection is required; all data is stored locally on this computer.

🔑 Rx Writer — Sign In

Sign In
  1. Type your username in the first field.
  2. Type your password in the second field.
  3. Click Sign In or press Enter.
ℹ️
First-time login credentials

Your username and initial password are provided by the person who set up Rx Writer at your clinic. If you do not know your credentials, contact your clinic administrator or reach out to info.rxwriter@gmail.com for setup assistance.

⚠️
Account lockout after 5 failed attempts

If the wrong password is entered 5 times in a row, the account is locked. An Administrator can unlock it from Administration → User Management. See Chapter 8 for details.

Changing Your Password on First Login

The first time you log in (or whenever an administrator resets your password), Rx Writer shows the Change Password dialog before opening the main window. This step is mandatory and cannot be skipped.

  1. Enter your current password (the temporary one the admin provided).
  2. Type your new password — minimum 8 characters.
  3. Re-type the new password in the Confirm Password field.
  4. Click Save. The main window opens.
✅
Password tips
  • Use at least 8 characters.
  • Mix uppercase, lowercase, numbers, and symbols.
  • Do not share your password with other users — each person should have their own account.

05

Prescriptions & Lab Tests

Writing medicine orders, ordering lab tests, and printing prescriptions

Doctor Admin   Only Doctor and Admin accounts (and custom roles with the WritePrescription permission) can access the Prescription tab.

Writing a Prescription

Open a patient visit (new or existing) and click the Prescription tab.

Adding a Medicine Line

  1. Select the Medicine Form — choose the drug form (Tablet, Capsule, Injection, Syrup, etc.) from the first dropdown. This narrows the medicine list and dosage/note choices.
  2. Select the Medicine — start typing the medicine name in the autocomplete field. Matching medicines from the catalog appear as you type. Select one, or type a custom name not in the catalog.
  3. Strength fills in automatically if the medicine is in the catalog. You can change it manually.
  4. Quantity — enter the number of units prescribed.
  5. Dosage — select a preset Dari dosage instruction (e.g. "یک قرص روزانه سه بار") or leave blank.
  6. Note — optionally select a preset medicine note (e.g. "با غذا مصرف شود").
  7. Click Add to add the line to the prescription table below.
✅
Cascading filters

Selecting a Medicine Form automatically filters the Dosage and Note dropdowns to show only items matching that form's category. This ensures you only see relevant dosage instructions.

Prescription Lines Table

Once added, each medicine appears in a numbered list. You can:

  • Click ✏ (Edit) to open the line in a dialog and change any field.
  • Click ✕ (Delete) to remove the line.
⚠️
Duplicate medicine guard

If you try to add the same medicine name twice, Rx Writer will warn you instead of adding a duplicate line.

Prescription Footer Note

At the bottom of the Prescription tab, select a Prescription Note from the dropdown (e.g. "در صورت مراجعه بعدی نسخه را با خود داشته باشید."). This note prints on the prescription PDF below the medicine list. Click ✕ Clear to remove it.

Ordering Lab Tests

On the right side of the Prescription tab, a panel shows all available lab tests grouped by category (e.g. Haematology, Microbiology, Biochemistry, Serology, Urinalysis).

Selecting tests

  1. Expand a category by clicking it.
  2. Check the boxes next to the tests you want to order.
  3. The selected tests appear as chip cards on the right side. Each chip shows the test name and abbreviation.
  4. Click ✕ on a chip to deselect that test.

Selected lab tests print in their own section on the prescription PDF, grouped by category with bold category headings.

Printing the Prescription PDF

Rx Writer generates a professional A4 portrait prescription PDF that matches the clinic's standard letterhead format.

How to print

  • In the Patient Edit window: click Save & Print or press Ctrl + P.
  • In the Patient List: click 🖨 Print next to any row.
  • In the Patient Detail window: click 🖨 Print next to any visit row.

The PDF opens in your default PDF viewer (e.g. Adobe Reader, Edge). Use the viewer's print function to send it to the printer.

Repeating a Previous Prescription

When a patient returns with the same condition, you can quickly create a new visit pre-filled with a previous visit's prescription.

  1. Open the patient's record from the Dashboard Recent Visits table (click Open). The Patient Detail window opens.
  2. Find the visit you want to repeat in the visit history list.
  3. Click ↻ Repeat on that row.
  4. A new Patient Edit window opens pre-filled with the same physician, diagnosis, clinical findings, prescription lines, lab tests, and footer note. Vitals are intentionally left blank for the doctor to update.
  5. Review the fields, update what has changed, then click Save or Save & Print.
ℹ️
A new visit record is always created

Repeating a prescription does not overwrite the original visit. A completely new visit record is saved with today's date.

06

Physicians

Managing doctor profiles used on prescriptions

Admin only   Click Physicians in the sidebar to open the Physicians page.

Physician profiles store the bilingual information that appears on every printed prescription header, as well as the clinic's contact and address details.

Physician Card Layout

Each physician is shown as a card containing their photo/logo (or initials if no image is uploaded), English name, Dari name, speciality, and contact phone number.

Adding a Physician

  1. Click + Add Physician.
  2. Fill in the English section: Full Name (English), Speciality (English), Contact Number, WhatsApp Number, Reception Number, Address.
  3. Fill in the Dari section: Full Name (دری), Speciality (دری). These print in the RTL right column of the prescription header.
  4. Optionally upload a Logo / Symbol image (PNG, JPG, or BMP). This image appears in the centre of the prescription header. If not uploaded, the physician's initials are shown instead.
  5. Click Save.
✅
Prescription header data

The Contact Number, WhatsApp Number, Reception Number, and Address all appear in the prescription PDF footer. Keep these up to date.

Editing or Deleting a Physician

  • Click ✏ Edit on the physician card to modify their details.
  • Click 🗑 Delete to remove a physician. A confirmation dialog appears. If any patients are linked to this physician, their physician field will be set to "None" (not deleted).

Linking a Physician to a User Account

When creating a Doctor user account (see Chapter 8 — User Management), you can link it to a physician profile. This allows the system to:

  • Show only that doctor's patients in their Patient List.
  • Show only their patients on the Dashboard.
  • Pre-select their physician when opening new visits.
07

Medicine Catalog

Managing the drug catalog used during prescription writing

Admin only   Click Medicines in the sidebar.

The Medicine Catalog is the list of all drugs that appear in the prescription autocomplete. Keeping this catalog up to date ensures prescriptions are written accurately and quickly.

Searching the Catalog

Type in the search box to filter medicines by name or generic name. Use the Category dropdown to filter by drug form category.

Adding a Medicine

  1. Click + Add Medicine.
  2. Enter the Medicine Name.
  3. Enter the Generic Name (optional).
  4. Select the Category (the drug form type, e.g. Tablet, Injection, Syrup).
  5. Enter the Strength (e.g. 500mg, 10ml).
  6. Click Save.

Editing or Deleting a Medicine

  • Click ✏ Edit on the row to modify a medicine's details.
  • Click 🗑 Delete to remove a medicine. A confirmation dialog appears. Deleting a medicine from the catalog does not affect existing prescriptions that already contain it.
⚠️
Autocomplete in prescriptions

The prescription form shows up to 25 matching medicines as you type. If a medicine is not in the catalog, you can still type it manually as a free-text entry — it just will not auto-fill the Strength field.

08

Administration

User accounts, roles, import, backup, and system configuration

Admin only   All items in the ADMINISTRATION sidebar section are visible only to Administrator accounts (and users with the ManageUsers permission).

User Management

Click Users to manage all clinic staff accounts.

The User List

All accounts are shown in a searchable table. Each row displays the username, full name, role, and a status badge:

  • Active — the user can log in normally.
  • Inactive — the user's account has been disabled by an admin. They cannot log in.
  • Locked — the user failed the password 5 times in a row and was automatically locked out.

Adding a User

  1. Click + Add User.
  2. Enter a unique Username.
  3. Enter the user's Full Name.
  4. Select a Role: Admin, Doctor, Receptionist, or any saved Custom Role.
  5. If the role is Doctor, link the account to a Physician profile using the Physician dropdown that appears. This scopes the doctor's patient list to their own patients.
  6. Enter a temporary Password and check "Must change password on next login" so the user sets their own password on first use.
  7. Click Save.

Actions Available per User Row

ActionWhat it does
✏ EditChange the user's name, role, or physician link. The username cannot be changed after creation.
Enable / DisableToggle the user's Active/Inactive status. Disabled users cannot log in.
🔓 UnlockClears the lockout flag. Shown only when the account is Locked. The user can then log in again.
🔑 Reset PasswordSet a new temporary password. The user must change it on next login.
🗑 DeletePermanently remove the account. You cannot delete your own account.
🚨
You cannot lock yourself out

Rx Writer prevents you from deactivating or deleting your own account. Always ensure at least one active Admin account exists.

Custom Roles

Click Custom Roles to define permission sets beyond the three built-in roles.

Custom roles are useful for staff who need access to a specific subset of features — for example, a Lab Technician who can view and print patient records but cannot write prescriptions, or a Pharmacist who can view the medicine catalog.

Creating a Custom Role

  1. Click + Add Role.
  2. Enter a unique Role Name (e.g. "Lab Technician").
  3. Enter a short Description.
  4. Check the permissions this role should have. Available permissions:
PermissionWhat it grants

  1. Optionally add Additional Notes — a free-text description of the role's responsibilities beyond the standard permission list.
  2. Click Save.

The new role immediately appears in the Role dropdown when creating or editing user accounts.

Deleting a Custom Role

When you delete a custom role, Rx Writer shows you the names of all users currently assigned to that role. Those users will be reverted to the Receptionist role. Confirm the deletion to proceed.

ℹ️
How custom roles appear in the UI

Users with custom roles see only the sidebar items their permissions allow — the same permission-gating that applies to built-in roles applies equally to custom roles.

Importing Data from Access

Click Import in the sidebar to import patient records from an existing Microsoft Access (.accdb) database.

⚠️
One-time operation

The import is designed for an initial migration from an existing Access clinic database. It is safe to run more than once (it skips tables that already have records), but it is not a sync — subsequent changes to the Access file are not imported automatically.

  1. Click Browse… and select your Access .accdb file.
  2. Click Start Import.
  3. Wait while Rx Writer reads all 10 data tables. A progress indicator appears during import.
  4. When complete, a results card shows how many records were imported from each table (Patients, Medicines, Lab Tests, Physicians, Dosages, Routes…).

Backup & Restore

Click Backup in the sidebar. The Backup & Restore page has three sections: Create, Restore, and Merge.

Creating a Backup

A backup is a copy of the entire clinic database saved to a file on your computer. Always keep recent backups, ideally on an external drive or USB stick as well.

  1. Choose a destination folder (or use the default).
  2. Optionally enter an encryption password. If you set a password, the backup is saved as an encrypted .rxb file. Without a password, it is saved as an unencrypted .zip.
  3. Click Create Backup.
  4. The backup file appears in the Saved Backups list below with its date, size, and an 🔒 Encrypted badge if password-protected.
🚨
Encryption password — write it down!

If you set an encryption password and forget it, the backup cannot be restored. Rx Writer does not store the password anywhere. Keep a record of it in a secure place.

Restoring a Backup

🚨
Restore replaces all current data

Restoring a backup overwrites the current database completely. All patient records, prescriptions, and settings added since that backup was made will be lost. Use this only when you need to recover from data loss or move the database to a new computer.

  1. Click Browse… in the Restore section and select a .zip or .rxb backup file, or click Restore next to a file in the Saved Backups list.
  2. If the backup is encrypted (🔒), enter the password in the field that appears.
  3. Read the warning and click Restore to confirm.
  4. Rx Writer verifies the backup's integrity, replaces the database, and automatically restarts.

Merging from Another Clinic

The Merge from Another Clinic card lets you import all patients and visits from a branch clinic's backup file without overwriting your own data. Both sets of records will coexist in the master database.

  1. Click Browse… and select the branch clinic's backup file (.zip or .rxb).
  2. Enter the Clinic Name for the branch (e.g. "Kandahar Branch"). This label will appear as a blue badge on every imported patient's row in the patient list.
  3. If the file is encrypted, enter the backup password.
  4. Click Merge. A progress log shows each step.
  5. When complete, a summary shows how many patients, visits, medicines, lab tests, and physicians were imported.
ℹ️
Merge is safe and additive

Merge never deletes or overwrites existing records. Physicians, medicines, and lab tests that already exist in the master database are reused (matched by name) rather than duplicated. Patient IDs are remapped so there are no conflicts.

Managing Saved Backups

The Saved Backups list shows all backup files in the default backup folder. You can:

  • Click Restore to restore from a specific backup.
  • Click 🗑 Delete to permanently remove an old backup file from disk.

Security & Session Management

Auto-lock, account lockout, and how to keep the clinic data safe

Automatic Session Lock

To protect patient data when a workstation is left unattended, Rx Writer automatically locks the screen after 10 minutes of inactivity.

🔒
Session Locked
Dr. Ahmad
Enter your password to continue:
••••••••
Unlock

When the lock screen appears:

  • The entire application is covered — no patient data is visible.
  • Any child windows (e.g. PatientEditWindow) that were open are also disabled.
  • Type your password and click Unlock (or press Enter) to resume.
ℹ️
Only the current user can unlock

The lock screen asks for the password of the user who is currently logged in. If that user has left and another person needs access, they must wait for the logged-in user to return, or an admin can log out the session by restarting the app.

Account Lockout (Failed Login Attempts)

If the wrong password is entered 5 times in a row at the Login window, the account is automatically locked with the status Locked 🔴. A locked account cannot log in even with the correct password.

How to unlock an account

  1. Log in with an Administrator account.
  2. Go to Administration → User Management.
  3. Find the locked account (it will show a red Locked badge).
  4. Click 🔓 Unlock. The account is immediately available for login again.
⚠️
What if the admin account itself is locked?

If the administrator's own account gets locked and no other admin account exists, contact your IT support. They can reset the lock directly in the clinic database file (%LocalAppData%\OPDClinic\clinic.db) using a SQLite database browser tool.

Audit Log

Rx Writer silently records key actions to an internal audit log. This log captures:

  • User logins and logouts
  • Session locks and unlocks
  • Patient record creation and updates
  • Prescription prints
  • User account changes (create, activate, deactivate, unlock, reset password, delete)
  • Backup creation and database restores
  • Data imports

The audit log is stored in the database and can be reviewed by your IT administrator or support team if needed.

Data Storage Location

All clinic data is stored locally in a single SQLite database file:

C:\Users\YourName\AppData\Local\OPDClinic\clinic.db

Application logs are written to:

Language Toggle

Switching the interface between English and Dari (دری)

Rx Writer supports two UI languages: English and Dari (دری). You can switch between them at any time without restarting the application.

How to Switch Language

At the bottom of the sidebar, find the language toggle button:

  • When the UI is in English, the button shows دری — click it to switch to Dari.
  • When the UI is in Dari, the button shows English — click it to switch back.

All menus, labels, dialogs, and buttons switch language instantly without closing any windows. The language preference is saved automatically and remembered the next time you open the app.

What changes with language

  • All sidebar labels and navigation items.
  • All dialog titles, field labels, and button text.
  • The layout direction: Dari uses Right-to-Left (RTL) and English uses Left-to-Right (LTR).

What does NOT change

  • Patient data, diagnoses, and clinical notes you have typed — these are stored exactly as entered.
  • The prescription PDF — it always uses both languages in the bilingual header regardless of the current UI language.
  • Sidebar icons — these stay left-aligned regardless of RTL mode, for consistent navigation.
  • Numeric fields (vitals) — these always use left-to-right text input regardless of language.
✅
Printed prescriptions are always bilingual

The prescription PDF header shows the clinic's English name on the left and the Dari name on the right, regardless of which language the app is currently using. This means prescriptions look correct for both English and Dari-speaking patients.

Software Updates

Keeping Rx Writer up to date with automatic and manual update checks

Automatic Update Check

Every time you start Rx Writer, it silently checks whether a newer version is available. This check runs in the background and does not slow down the application startup. If a newer version is found, an Update Available dialog appears after the main window loads.

To avoid checking too frequently, the automatic check is limited to once every 24 hours.

Manual Update Check

Click Check for Updates in the sidebar (at the bottom, near the language toggle) to check immediately regardless of the 24-hour cooldown. This is useful after being told a new update is available.

  • If an update is available, the Update Available dialog appears.
  • If you are already on the latest version, a message confirms "You are up to date."
  • If the check fails (e.g. no internet connection), a warning message is shown.

Installing an Update

When the Update Available dialog appears:

  1. Read the release notes to see what has changed in the new version.
  2. Click Update Now to download and install the update. Rx Writer closes automatically and the installer runs silently.
  3. After installation, Rx Writer opens again with the new version. Your data is always preserved during an update.
  4. Alternatively, click Later to dismiss the dialog and continue working. The update will be offered again next time.
⚠️
Internet connection required

The update check and download require an active internet connection. If the clinic computer does not have internet access, contact your IT support to download and install the update manually.

✅
Check the current version

The current version number (e.g. v2.0.4) is always shown at the bottom of the sidebar in small italic text. You can also see it in the About dialog (click About at the bottom of the sidebar).

Troubleshooting & FAQ

Common questions and how to resolve them

I cannot log in — the app says my account is locked

Your account was automatically locked after 5 consecutive failed login attempts. Ask your Administrator to unlock it from Administration → User Management → 🔓 Unlock.

I forgot my password

Contact your Administrator. They can reset your password from Administration → User Management → 🔑 Reset Password. You will be required to set a new password on your next login.

The prescription PDF opens but does not print correctly on my B&W printer

Go to Administration → Print Settings and click Apply B&W Palette. This converts all section colours to printer-optimised grayscale values. Then click Save Settings.

I restored a backup but now I am missing recent records

A restore replaces the entire database with the backup's contents. If records were added after the backup was made, those records are lost. This is why regular, frequent backups are essential. If you have a more recent backup, restore from that file instead.

The backup I created on this computer restored without asking for a password on another computer

Only encrypted backups (.rxb files) require a password on restore. If you saved the backup without entering an encryption password, it was saved as an unencrypted .zip file. Always set an encryption password if you plan to store or transfer backups across computers.

A patient's records are not showing in my Patient List

If you are logged in as a Doctor, the patient list is automatically filtered to show only your patients (those linked to your physician profile). If you expect to see another doctor's patients, ask an Administrator to check your account settings.

Also check whether any physician or date filters are active — clear them using the dropdown or date picker.

The app is running slowly / the database is very large

Check the Database Size card on the Dashboard. For normal clinic volumes the database is typically under 10 MB. If the size seems unexpectedly large, contact your IT support to inspect the database file.

I accidentally deleted a patient record — can I recover it?

Rx Writer does not have a recycle bin or an undo feature for deletions. Restore your most recent backup that contains the deleted record. This will overwrite all data added since that backup, so consider carefully before restoring.

Rx Writer shows an error on startup

Check the application log files at:

C:\Users\YourName\AppData\Local\OPDClinic\Logs\

Share the most recent log file with your IT support or send it to info.rxwriter@gmail.com for assistance.

How do I move Rx Writer to a new computer?

  1. On the old computer, go to Backup & Restore and create a backup with an encryption password.
  2. Copy the backup file (.rxb) to a USB drive.
  3. Install Rx Writer on the new computer using the installer.
  4. Open Rx Writer on the new computer and log in using your administrator credentials, then immediately go to Backup & Restore → Restore.
  5. Select the backup file from the USB drive, enter the password, and restore. The app restarts with all your data.
